# NuelNexus — Personal Portfolio

Welcome to **NuelNexus**, my personal portfolio website, built to showcase my journey, skills, projects, and interests in technology.

I'm a Biochemistry undergraduate at the Federal University of Technology, Owerri (FUTO), with a strong interest in Fullstack Web Development and Bioinformatics. This portfolio represents my growth as a developer and my commitment to building practical, useful digital solutions.

## 🚀 About the Project

NuelNexus is a multi-page personal portfolio website designed to introduce me, showcase my work, highlight the services I can offer, share articles about my learning journey, and provide a way for people to connect with me.

The website was built with a focus on clean design, responsive layouts, smooth animations, and straightforward navigation.

## ✨ Features

- **Home:** An introduction to who I am and what I do.
- **About:** My background, education, interests, and development journey.
- **Work:** A showcase of my programming projects and practical work.
- **Services:** An overview of the web development services I can offer.
- **Blog:** Articles covering technology, programming, learning, and my personal journey.
- **Contact:** A contact section that allows visitors to reach out to me.

### Additional Features

- Responsive design for different screen sizes.
- Smooth scroll animations using AOS.
- Interactive navigation.
- Blog article navigation.
- Contact form with Gmail integration.
- Downloadable CV.
- Back-to-top navigation.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, responsiveness, and visual design.
- **JavaScript** — Interactive functionality and dynamic behaviour.
- **AOS (Animate On Scroll)** — Scroll-based animations.
- **Google Fonts (Poppins)** — Typography.
- **Font Awesome** — Icons.

## 💻 Running the Project Locally

To view the website on your computer:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `frontend/index.html` in your browser, or use the VS Code Live Server extension.
